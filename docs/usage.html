主な使い方

本サービスは、各サイトのWeb記事を一覧で見渡すための「ビューア」として設計しています。機能は、あとで試したい記事を残しておくためのブックマークだけに絞っています。

記事を読む

  • 記事タイトル（またはサムネイル）をタップすると、元の記事が新しいタブで開きます。
  • 上部のタブで、カテゴリごとに絞り込めます。「ニュース」は知っておきたい新機能・発表、「AI活用」「Office Tips」「Windows Tips」は自分で試せる使い方の記事です。
  • 「すぐ試せる」のバッジが付いた記事は、手順やプロンプト例など、読みながらそのまま試せる内容です。
  • 「英語・翻訳で開く」のバッジが付いた記事は元が英語のため、Google翻訳で日本語に訳したページが開きます（会社のネットワークによっては翻訳ページが開けない場合があります）。
  • 一度開いた記事はタイトルの色が薄くなるので、未読の記事がひと目で分かります。

表示を切り替える

  • 右上の月／太陽のボタンで、ライト表示とダーク表示を切り替えられます。選んだ表示はブラウザに保存され、次回も同じ表示で開きます。

ブックマークする

  • 「あとで試したい」と思った記事は、右上の ☆ をタップするとブックマークできます（★ になります）。
  • ブックマークした記事は「ブックマーク」タブにまとまり、日付が変わっても見返せます（過去90日分まで）。
  • もう一度 ★ をタップするとブックマークを解除できます。

ブックマークについてのご注意

ブックマークは、お使いのブラウザの中に保存されます。仕組みをシンプルに保つため、PCとスマホなど別の端末・別のブラウザ間での同期には対応しない方針としています。また、ブラウザの閲覧データ（サイトデータ）を削除すると、ブックマークも消えてしまいますのでご注意ください。
